### ***\*\*\*ENGLISH\*\*\****

The project started when I asked OpenAI ChatGPT to generate a project, which would highlight skills relevant for an Information and Knowledge Management student. The AI came up with an end-to-end project, framed as "Business Intelligence and decision-support system" for a fictional European e-commerce company. I received a dataset with 18,000 customers, 62,000 orders, 114,453 order items, 60 different products and 8 different European markets. The AI had purposefully created realistic problems so I could demonstrate my data cleaning skills such as, duplicate customer records, mixed order-date formats and inconsistent country capitalization. I was also given a data dictionary that told me what each table represents, what each column means and so on.

The AI advised me to have one file for analysing the raw data, and another one for the actual code. So "raw-data.py" contains data-profiling and investigatory code, and "clean-data.py" contains handwritten code for all files.

After cleaning the data, it was time to create a database and move onto performing SQL queries. I settled on SQLite as I have used it before in school. I handwrote the "schema.sql" file that defined the database. My next task was to answer some "business questions" with SQL. I created SQL files that gave information about the business like, monthly revenue and profit, sales by country, product-specific sales or conversion rate of campaigns. I learned the hard way how easy it is to duplicate rows unintentionally.

During SQL analysis, I noticed that the customer ages showed an unusually large concentration at age 18. Upon questioning the AI about this, I found out that this was caused by the synthetic data-generation method used by the AI: a lower-bound clipping rule assigned all generated ages below 18 to 18. Age-based analysis was therefore treated with caution, but kept unchanged for the sake of demonstration.

For the sake of honesty, my impatience directed me to rely on the AI when running into roadblocks such as, setting up a virtual environment, designing the project folder or any small mistakes I made along the way. However the implementation itself was written and worked through manually. I thought the interaction was similar to consulting a more experienced colleague. Asking for explanations or direction when needed while ensuring that I understood and implemented everything myself.

Then it was time to create a Power BI dashboard, that shows some quick information about the company. This part of the project took the longest, as graphic design is not my strong suit. The dashboard underwent multiple changes and versions. I learned several practical Power BI skills, including when to use cards versus KPI visuals, how to approach a sensible way to bring data to life. I'm very pleased with the outcome.



### ***\*\*\*SUOMI\*\*\****

Projekti alkoi, kun pyysin OpenAI ChatGPT:tä generoimaan minulle projektin, joka toisi esiin tietojohtamisen opiskelijalle olennaisia taitoja. Tekoäly ehdotti päästä päähän toteutettavaa projektia, joka kuvattiin fiktiivisen eurooppalaisen verkkokaupan Business Intelligence- ja päätöksenteon tukijärjestelmäksi. Sain aineiston, joka sisälsi 18 000 asiakasta, 62 000 tilausta, 114 453 tilausriviä, 60 eri tuotetta ja kahdeksan eri Euroopan markkina-aluetta. Aineistoon oli tarkoituksella luotu realistisia datan laatuun liittyviä ongelmia, jotta pystyin osoittamaan datan puhdistamiseen liittyviä taitojani. Näitä olivat esimerkiksi päällekkäiset asiakastietueet, eri muodoissa olevat päivämäärät sekä epäjohdonmukainen maiden nimien kirjoitusasu. Sain myös data dictionary -tiedoston, jossa kuvattiin, mitä kukin taulu ja sarake tarkoittaa.

Tekoäly neuvoi minua pitämään raakadataan liittyvän analyysin ja varsinaisen puhdistuskoodin erillään. Tämän vuoksi raw-data.py sisältää datan profilointiin ja tutkimiseen liittyvän koodin, kun taas clean-data.py sisältää itse kirjoittamani puhdistus- ja käsittelykoodin kaikille tiedostoille.

Datan puhdistamisen jälkeen seuraava vaihe oli tietokannan luominen ja SQL-kyselyihin siirtyminen. Valitsin SQLite-tietokannan, koska olin käyttänyt sitä aikaisemmin koulussa. Kirjoitin itse schema.sql-tiedoston, joka määritteli tietokannan rakenteen. Seuraavana tehtävänäni oli vastata SQL:n avulla erilaisiin liiketoimintakysymyksiin. Loin SQL-tiedostoja, joiden avulla tarkastelin esimerkiksi kuukausittaista liikevaihtoa ja voittoa, myyntiä maittain, tuotekohtaista myyntiä sekä markkinointikampanjoiden konversioasteita. Opin kantapään kautta, kuinka helposti rivejä voi SQL-liitoksissa vahingossa monistaa.

SQL-analyysin aikana huomasin, että 18-vuotiaiden asiakkaiden määrä oli aineistossa poikkeuksellisen suuri. Selvitettyäni asiaa tekoälyn kanssa kävi ilmi, että tämä johtui tekoälyn käyttämän synteettisen aineiston generointitavasta: kaikki alle 18-vuotiaiksi generoidut iät oli rajattu arvoksi 18. Tämän vuoksi ikään perustuvaan analyysiin suhtauduttiin varauksella, mutta havainto jätettiin aineistoon tarkoituksella osoittamaan datan laadun arviointia.

Rehellisyyden vuoksi myönnän hyödyntäneeni tekoälyä odottamattomuuden vaikuttamana kun kohtasin projektin aikana ongelmia esimerkiksi virtuaaliympäristön määrittämisessä, projektin kansiorakenteen suunnittelussa tai pienempien virheiden ratkaisemisessa. Toteutin varsinaisen toteutuksen kuitenkin itse, ja kävin ratkaisut läpi niin, että ymmärsin mitä olin tekemässä. Ajattelin tekoälyn käyttöä samalla tavalla kuin kokeneemmalta kollegalta kysymist: pyysin tarvittaessa selityksiä tai suuntaa, mutta huolehdin siitä, että ymmärsin ja toteutin ratkaisut itse.

Lopuksi oli aika rakentaa Power BI -dashboard, joka esittää nopeasti keskeistä tietoa yrityksen toiminnasta. Tämä vaihe vei projektissa eniten aikaa, sillä visuaalinen suunnittelu ei ole vahvin osaamisalueeni. Dashboard kävi läpi useita eri versioita ja muutoksia. Opin projektin aikana useita käytännön Power BI -taitoja, kuten milloin kannattaa käyttää kortteja ja milloin KPI-visualisointeja sekä miten dataa voidaan esittää selkeästi ja tarkoituksenmukaisesti. Olen lopputulokseen erittäin tyytyväinen.
